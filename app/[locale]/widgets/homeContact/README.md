# HomeContact — контакты главной

Серверный блок `#contact`, тексты — `messages.home.contact`.
Общий email берётся из `shared/config/site.ts`; mailto лишь открывает почтовый
клиент пользователя и ничего автоматически не отправляет.
Расположение и размер текста — соседний SCSS-модуль.
