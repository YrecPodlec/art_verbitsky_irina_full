# SiteHeader — фиксированная шапка интерьера

Подключена только в `app/[locale]/(pages)/interior/layout.tsx`.
У главной своя [HomeHeader](../homeHeader/README.md); общий locale-layout шапку не навязывает.

| Файл | Что менять |
| --- | --- |
| [ui/SiteHeader.tsx](ui/SiteHeader.tsx) | Логотип, массив ссылок, состав действий и мобильное меню |
| [ui/SiteHeader.module.scss](ui/SiteHeader.module.scss) | Шапку, отступы, размеры, адаптив и раскрытие меню |
| [ui/NavLink.tsx](ui/NavLink.tsx) | Общую ссылку меню и определение активной страницы |
| [ui/NavLink.module.scss](ui/NavLink.module.scss) | Вид ссылок, мобильный и акцентный варианты |

Язык и профиль — отдельные features:
[LanguageSwitcher](../../features/languageSwitcher/README.md),
[ProfileButton](../../features/profileButton/README.md).
Тексты шапки находятся в `messages.siteHeader`.

## Почему здесь refs и effects

`menuOpen` хранит состояние меню.
`headerRef` даёт доступ к DOM-шапке для двух задач:
измерить её высоту и определить клик снаружи.

Шапка `position: fixed` не занимает места в потоке страницы.
Общий хук `shared/lib/layout/useFixedHeaderOffset.ts` через `ResizeObserver`
измеряет высоту и записывает `--site-header-offset` и `--fixed-header-height`.
`FixedHeaderShell` использует высоту для места над контентом, html — для якорей.
Глобального отступа на body больше нет, чтобы страницы без шапки не имели пустой полосы.
Для Interior сохранена дополнительная поправка якорей **-5rem** во втором аргументе
`useFixedHeaderOffset`. Она не меняет высоту шапки или отступ контента.
Фиксированная высота самой шапке не задаётся: используются padding и содержимое.

Второй effect, пока меню открыто, слушает клик снаружи и Escape.
Cleanup снимает обработчики; первый effect также отключает observer
и удаляет измеренное значение переменной при размонтировании.

`useId` создаёт ID мобильного меню. `aria-controls` связывает кнопку с ним,
`aria-expanded` сообщает состояние, `inert` выключает взаимодействие с закрытым меню.
`small` в названии бренда — HTML-элемент дополнительной подписи.

## Изменить меню или логотип

Массив `links` используется для десктопных и мобильных ссылок.
Новый `id` должен иметь перевод в `siteHeader`, а `href` — существующий маршрут.
Домашняя ссылка мобильного меню задана отдельно.
`NavLink` сравнивает текущий pathname с href; `accented` включает акцентный стиль.
Ромбик и стрелка шоурума добавляются отдельно в JSX шапки.

Логотип сейчас — `logoPlaceholder` с «IV». Замени его на изображение,
проверь отступы и измерение шапки после загрузки.

Проверяй мобильное меню, клик вне него, Escape, Tab, длинные переводы
и отсутствие перекрытия первого экрана фиксированной шапкой.
[Назад к widgets](../README.md).
