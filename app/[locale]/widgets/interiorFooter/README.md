# InteriorFooter — подвал интерьера

[ui/InteriorFooter.tsx](ui/InteriorFooter.tsx) подключается после `main`
в странице интерьера. В общем layout его сейчас нет.

Собственные тексты берутся из `messages.interiorFooter`.
Имя бренда и подписи галереи/услуг/статей/шоурума переиспользуются из `siteHeader`.

Для изменения маршрутов редактируй ссылки в TSX.
Для размера имени, колонок, цветов и адаптива —
[ui/InteriorFooter.module.scss](ui/InteriorFooter.module.scss).
Для текста профиля смотри [ProfileButton](../../features/profileButton/README.md):
он пока неактивен. Локальный SCSS футера уточняет его оформление.

Если футер понадобится другим страницам, реши, должен ли он быть общим в layout
или подключаться к выбранным маршрутам. При переносе убери прежнее подключение,
чтобы не получить два футера на interior.

Проверяй переходы к услугам/контактам, ссылки обеих локалей и перенос большого имени.
Контакты и юридические сведения пока обозначены как требующие согласования.
[Назад к widgets](../README.md).
