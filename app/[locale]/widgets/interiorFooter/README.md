# InteriorFooter — совместимый старый импорт

Отдельной разметки/SCSS здесь больше нет. `index.ts` экспортирует общий
`SiteFooter` под старым именем, чтобы прежние импорты не ломались.

Новый код импортирует `widgets/siteFooter` напрямую. Тексты — `messages.siteFooter`,
направления — общий mock-массив. [Документация общего футера](../siteFooter/README.md).
