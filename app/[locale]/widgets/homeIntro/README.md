# HomeIntro — авторский блок главной

Серверный `ui/HomeIntro.tsx`: один h1, описание, ссылка к направлениям и крупный
портрет `public/interior/irina.jpg` без фильтров. Тексты — `home.intro` в messages.
Фотография имеет естественные пропорции. Размер — `.portrait` в соседнем SCSS.
Номер последнего направления берётся из общего массива, не записан вручную.
