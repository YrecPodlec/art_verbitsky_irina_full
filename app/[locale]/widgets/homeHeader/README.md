# HomeHeader — отдельная фиксированная шапка главной

`ui/HomeHeader.tsx` переводит подписи на сервере из `home.header`.
`ui/HomeHeaderView.tsx` хранит только состояние мобильного меню и ref шапки;
язык — готовая feature `LanguageSwitcher`, без второго переключателя RU/EN.
SCSS-модуль рядом задаёт dark-оформление и адаптив. Fixed-высота не задана.

Общий `useFixedHeaderOffset` измеряет размер; `FixedHeaderShell` оставляет место.
Desktop/mobile ссылки ведут на `/#directions`, `/#about`, `/#contact`, поэтому
работают и со страницы `/art`. Escape/клик вне шапки закрывают мобильное меню.
Флаги и выпадающий список не скрываются вместе с мобильным меню.

Шапка подключена в `(home)/layout.tsx`, не на всех страницах.
Общая карта — [главная](../../(home)/README.md).
