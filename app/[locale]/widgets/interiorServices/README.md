# InteriorServices — услуги и стоимость

Серверный раздел с якорем `services`.
[ui/InteriorServices.tsx](ui/InteriorServices.tsx) получает переводы `services`
и пакеты через `getServices`, затем соединяет карточки, особый подход и консультации.

## Где редактировать

| Изменение | Место |
| --- | --- |
| Заголовок, описание, примечания | `messages.services` |
| Набор пакетов и допустимые услуги | [entities/service](../../entities/service/README.md) |
| Вид одной карточки | `entities/service/ui/ServiceCard.module.scss` |
| Переключение варианта, перенос услуги в форму | [projectInquiry](../../features/projectInquiry/README.md) |
| Сетка карточек, особый подход, строки консультаций | [ui/InteriorServices.module.scss](ui/InteriorServices.module.scss) |
| Общие заголовки и отступы | `shared/UI/section` |

`ServicePackageChoice` содержит состояние выбранного варианта.
`ServiceChoiceLink` используется также у особого подхода и консультаций.
Для их работы раздел должен находиться внутри `InquiryProvider`, как на странице интерьера.

В `labels` передаются общие цена, единица, подпись выбора и примечание.
Стоимость сейчас задаётся словами «По согласованию»; числовая модель цены отсутствует.

На широком экране — три карточки, до 50rem — одна колонка;
сама карточка при этом имеет планшетную раскладку.
Проверяй оба варианта каждого тарифа и правильную услугу в форме после выбора.
