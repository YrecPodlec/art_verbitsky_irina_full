# Приветственный блок Interior Design

`ui/InteriorHero.tsx` — серверный компонент первого экрана из `maket/index.html`.
`model/actions.ts` хранит порядок ссылок и маршруты, а все тексты, включая метаданные
и описание изображения, находятся в `messages/*.json` в разделе `interiorHero`.

Теги `<br></br>` задают переносы строк, `<accent>...</accent>` выделяет часть заголовка.
При добавлении языка переводится словарь, а не компоненты.

Кнопки переходов — общий компонент `shared/UI/actionLink/ActionLink.tsx`:

```tsx
<ActionLink href="/gallery" size="small" variant="outline">
  {t('gallery')}
</ActionLink>
```

Размеры: `small` и `large`. Оформление: `text`, `outline`, `gold`, `green`, `path`.
`caption` добавляет подпись, `index` — декоративный номер, `className` — стили расположения.
`direction="down"` меняет стрелку для перехода к следующей секции; по умолчанию она направлена вверх-вправо.
Для действий без перехода используется `ActionButton` из того же среза: общие стили и содержимое не дублируются.
Стрелка и прозрачный зелёный фон анимируются в SCSS; дополнительные хуки не нужны.

Палитра и длительность анимаций заданы в `globals.css`. Размеры и отступы используют
шаг `.25rem`, тонкие декоративные линии сохраняют толщину из макета.
Отступ от фиксированной шапки учитывается через `--site-header-offset`.

Страница передаёт хлебные крошки через проп `breadcrumbs`. Виджет располагает их
над вводной строкой, а иерархия страниц хранится отдельно в `shared/config/navigation.ts`.
`shared/lib/navigation/getBreadcrumbs.ts` строит цепочку, `getLocalizedBreadcrumbs.ts`
добавляет серверные переводы, `shared/UI/breadcrumbs` отображает готовые элементы.

## Проверка

Запустить `npm run lint` и `npm run build`. Затем сравнить `/ru/interior` и `/en/interior`
с макетом на широком экране, около брейкпоинтов 800 и 520 px и на телефоне.
Проверить наведение, Tab, фокус ссылки и настройку уменьшения движения.
При увеличении масштаба текст и ссылки не должны перекрываться.

Ссылки на `#projects` и `#services` прокручивают к готовым секциям. `/showroom` — отдельный маршрут.
