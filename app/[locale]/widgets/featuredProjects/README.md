# Избранные проекты

`FeaturedProjects` — второй серверный виджет страницы `/[locale]/interior`.
Он повторяет подборку из `maket/index.html`: заголовок, три проекта, ссылку на галерею
и нижнюю строку. По отдельному запросу добавлена ссылка на 3D-шоурум через общий `ActionLink`.

## Кто за что отвечает

- `entities/project/model/projects.ts` — идентификаторы, изображения и кадрирование из макета.
  `featured` означает редакционную подборку, а не проекты, сохранённые пользователем.
- `entities/project/model/getProjects.ts` — серверная подготовка данных с переводами из `messages`.
- `entities/project/ui/ProjectCard.tsx` — общая карточка, пригодная и для страницы галереи.
  `compact` включает плотный планшетный вариант из макета, `imageSizes` описывает размер изображения.
- `features/favoriteProject` — отдельная кнопка будущего избранного.
- `widgets/featuredProjects` — собирает карточки и передаёт кнопку через `favoriteAction`.
  Карточка не импортирует feature: этот слот позволяет избежать обратной зависимости FSD.

```tsx
<ProjectCard project={project} href={`/gallery/${project.id}`} />
```

Это пример будущего использования **после создания маршрута кейса**.
Сейчас `href` не передаётся, чтобы карточки не открывали несуществующие страницы.
Сердечки видны, но отключены с пояснением: аккаунта и API избранного ещё нет.
Когда они появятся, кнопку можно сделать клиентской, оставив карточку и виджет серверными.

Изображения и подписи демонстрационные, как в макете; свойства реальных проектов не выдумываются.
Весь отображаемый текст находится в разделах `featuredProjects`, `projects`, `projectCard`
и `favoriteProject` в `messages/*.json`. Для нового языка достаточно перевести эти ключи.

## Проверка

`npm run lint` и `npm run build` проверяют код и сборку.
В браузере сравнить `/ru/interior` и `/en/interior` с макетом на широком экране,
около 800 и 520 px и на телефоне. На планшете остаются три карточки, на телефоне — одна в ряд.
Проверить изображения, переходы в галерею/шоурум, якорь `#projects`, Tab и уменьшение движения.
Ссылка `#services` ведёт к секции услуг. Общая верхняя строка, заголовок и отступы
теперь переиспользуются из `shared/UI/section`, сохраняя оформление второго блока.
