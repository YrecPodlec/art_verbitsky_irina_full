# Приложение для выбранного языка

Здесь лежат маршруты и компоненты работающего сайта. `[locale]` в адресе заменяется
на `ru` или `en`. Общая карта — в [корневом README](../../README.md).

## Куда идти

| Папка или файл | Что здесь менять |
| --- | --- |
| [layout.tsx](layout.tsx) | Общую техническую оболочку и словарь клиентских компонентов, без конкретной шапки |
| [(home)](<(home)/README.md>) | Новую главную `/ru` или `/en`, её layout и Art-заготовку |
| [(pages)](<(pages)/README.md>) | Состав отдельных страниц |
| [widgets](widgets/README.md) | Крупные блоки: первый экран, проекты, услуги, контакты |
| [features](features/README.md) | Действия: выбор тарифа, форма, язык, навигация |
| [entities](entities/README.md) | Данные и общие карточки проектов и услуг |
| [shared](shared/README.md) | Переиспользуемые кнопки, поля, заголовки, функции и ресурсы |
| [globals.css](globals.css) | Общие цвета, шрифты, базовые стили и скорости анимации |
| [fonts](fonts/README.md) | Подключённые файлы шрифтов |
| [styles](styles/README.md) | Стили исходной главной страницы |

Тексты редактируются в [messages](../../messages/README.md), языковые настройки —
в [i18n](../../i18n/README.md), фотографии — в [public](../../public/README.md).

## Что делает layout

`layout.tsx` проверяет язык, устанавливает его для серверного рендера и создаёт
`html` с нужным `lang`. Здесь подключены глобальные стили, но не конкретная шапка.
`generateStaticParams` перечисляет языки из `routing.locales`.

`NextIntlClientProvider` передаёт клиенту только `siteHeader`.
Новый клиентский компонент с другим `useTranslations` потребует передачи его словаря
или готовых переведённых строк через props. Серверные блоки получают перевод сами.

Новая главная собирается в `(home)/page.tsx`, её шапка — в `(home)/layout.tsx`.
Массив направлений — `entities/direction/model/directions.mock.json`.
Переводы — `home` и `siteFooter`; общий email — `shared/config/site.ts`.
`SiteHeader` подключён только в `(pages)/interior/layout.tsx` через `FixedHeaderShell`.
Интерьер собирается в [(pages)/interior/page.tsx](<(pages)/interior/page.tsx>).

## Как читать компонент

Сначала прочитай README его папки, затем TSX и соседний SCSS-модуль.
`ui` содержит представление, `model` — данные и поведение.
Импорты показывают, какие общие части использует компонент. Правила слоёв —
в [архитектуре](../../docs/architecture.md).
