# Pagination — нумерованная навигация

`Pagination.tsx` — серверный компонент без состояния и обработчиков клика.
Переходы оформлены как кнопки, но остаются ссылками: их можно открыть в новой вкладке.
SCSS-модуль рядом отвечает за одинаковые размеры, цвета, фокус и мобильный перенос.

## Props

- `currentPage`, `totalPages` — текущая страница и общее количество.
- `hrefForPage(page)` — функция, собирающая адрес с нужными фильтрами.
- `labels` — переведённые подписи навигации, стрелок и номеров из `messages`.
- `className` — необязательное внешнее оформление.

Все номера отображаются без многоточия; текущий выделен и имеет `aria-current="page"`.
Обе стрелки видны всегда, даже если страница одна. На границах используются настоящие
`button disabled`, а не рабочие ссылки с притворным неактивным видом.
Рисунок стрелки — `shared/UI/icons/ArrowHorizontal.tsx`, он не зависит от `ActionLink`.
Prefetch отключён, чтобы появление всех номеров не запускало лишние запросы к MongoDB.

В каталоге лимит задаёт `entities/project/model/catalogQuery.ts` → `CATALOG_PAGE_SIZE = 6`.
Страница передаёт адреса через `catalogHref`: фильтры, поиск и локаль сохраняются.
Компонент не меняет сортировку и не знает о БД. Внешние отступы — в SCSS страницы.

Проверка: `npm run test:portfolio` и при работающем Next
`npm run test:portfolio:http -- --all-projects` (только GET).
