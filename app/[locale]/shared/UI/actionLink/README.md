# Общая кнопка и ссылка со стрелкой

Начни здесь, если хочешь изменить основную повторяющуюся кнопку сайта.
Эта папка обслуживает переходы в шоурум, ссылки секций и кнопки контактной формы.

## Почему здесь несколько файлов

| Файл | Ответственность | Когда менять |
| --- | --- | --- |
| [ActionLink.tsx](ActionLink.tsx) | Обёртка над локализованной ссылкой | Props ссылки, переходы и её HTML-обёртка |
| [ActionButton.tsx](ActionButton.tsx) | Настоящий `button` | Props действия, тип и обработчики кнопки |
| [ActionContent.tsx](ActionContent.tsx) | Общая внутренняя разметка и сборка классов | Порядок текста, подписи, номера и стрелки; общие варианты |
| [ActionLink.module.scss](ActionLink.module.scss) | Общие стили обоих компонентов | Размеры, цвета, шрифт, рамка, наведение и движение |
| [index.ts](index.ts) | Экспорты компонентов и типа ссылки | Публичный импорт из этой папки |

Одинаковый внешний вид сохраняется благодаря `ActionContent` и одному SCSS-модулю.
`ActionLink` нужен для перехода; `ActionButton` — для действия или отправки формы.

## Что именно редактировать

| Хочу изменить | Где искать |
| --- | --- |
| Общий шрифт, расстояние между текстом и стрелкой | SCSS: `.link` |
| Размер текста и отступы | SCSS: `.small`, `.large` |
| Золотую заливку | SCSS: `.gold`; цвет берётся из `--color-gold` |
| Кнопку с рамкой | SCSS: `.outline` |
| Зелёную кнопку | SCSS: `.green` |
| Текстовую ссылку с нижней линией | SCSS: `.text` |
| Переходы первого экрана | SCSS: `.path` и его media-правила |
| Зелёный прозрачный слой при наведении | SCSS: `.link::before`; цвет `--color-hover` |
| Размер или движение стрелки | SCSS: `.arrow`, `--arrow-size`, hover и `.down` |
| Форму самой стрелки | SVG в [icons](../icons/README.md) |
| Внутреннюю разметку всех вариантов | `ActionContent.tsx` |
| Текст конкретной кнопки | Перевод, который передаёт вызывающий widget или feature |
| Адрес конкретного перехода | `href` в месте использования |

Если меняется только одна кнопка, сначала проверь её `variant`, `size` и `className`
в вызывающем компоненте. Изменение общего `.link` затронет все применения.
`.path` и media-правила могут переопределять общие размеры.

## Props

| Prop | Значения / назначение |
| --- | --- |
| `children` | Текст или готовая разметка подписи |
| `variant` | `text` (по умолчанию), `outline`, `gold`, `green`, `path` |
| `size` | `small` (по умолчанию), `large` |
| `direction` | `upRight` (по умолчанию) или `down` |
| `caption` | Дополнительная строка над основным текстом |
| `index` | Декоративный номер, например `01` |
| `className` | Дополнительный класс расположения |
| `href` | Только у ссылки: маршрут или якорь |
| `type` | Только у кнопки: по умолчанию `button`; для формы `submit` |

Остальные подходящие props передаются в ссылку или кнопку:
например, `onClick`, `disabled` у кнопки, `aria-label`, `locale` у ссылки.

## Использование

Импорт:

```tsx
import {ActionLink, ActionButton} from '@/app/[locale]/shared/UI/actionLink';
```

Примеры внутри компонента с подготовленными переводами:

```tsx
<ActionLink href="/showroom" variant="gold" size="large">
  {t('showroom')}
</ActionLink>

<ActionLink href="#services" direction="down">
  {t('chooseService')}
</ActionLink>

<ActionButton type="submit" variant="gold" disabled={!ready}>
  {copy.submit}
</ActionButton>
```

Обработчик `onClick` задаётся внутри клиентского компонента.
Серверный widget может использовать ссылку без обработчика. Сами общие компоненты
не имеют состояния и не содержат переводов: подписи готовит вызывающая часть.

При изменении проверь первый экран, шоурум и форму; размеры на телефоне;
Tab и видимый фокус; поведение `disabled`; уменьшение движения.
Назад к [каталогу UI](../README.md).
