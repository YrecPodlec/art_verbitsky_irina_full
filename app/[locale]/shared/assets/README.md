# Импортируемые ресурсы

Здесь лежат общие файлы, которые компоненты импортируют из исходников.

В `flags/`:

- `ru.svg` — флаг для русского языка.
- `us.svg` — флаг США для английского.
- [SOURCE.md](flags/SOURCE.md) — источник, версия набора и назначение флагов.
- [LICENSE.flag-icons](flags/LICENSE.flag-icons) — условия использования.

Флаги импортируются в [LanguageSwitcher](../../features/languageSwitcher/README.md).
Чтобы добавить флаг, положи файл в `flags`, импортируй его в переключатель
и добавь в объект `flags` по коду языка. Сохраняй сведения об источнике и лицензии.
У языка без флага переключатель показывает глобус.

Фотографии ищи в [public](../../../../public/README.md), подключённые шрифты —
в [fonts](../../fonts/README.md). Не все ресурсы сайта должны лежать в одной папке.
[Назад к shared](../README.md).
