# Shared — общие части сайта

Здесь находятся элементы, которые можно использовать без знания конкретного проекта,
тарифа или аккаунта. Карточки предметов сайта ищи в [entities](../entities/README.md),
действия пользователя — в [features](../features/README.md).

| Папка | Назначение |
| --- | --- |
| [UI](UI/README.md) | Кнопки, поля, заголовки, хлебные крошки и другие элементы интерфейса |
| [assets](assets/README.md) | Импортируемые ресурсы, сейчас — флаги |
| [config](config/README.md) | Общая конфигурация, сейчас — иерархия страниц |
| [lib](lib/README.md) | Общие функции, сейчас — построение хлебных крошек |

## Где редактировать

Для изменения общей кнопки открой [actionLink/README.md](UI/actionLink/README.md).
Для изменения структуры крошек — [lib/navigation/README.md](lib/navigation/README.md).
Фотографии интерьера лежат в [public](../../../public/README.md), шрифты —
в [fonts](../fonts/README.md), глобальная палитра — в `../globals.css`.

UI получает данные и тексты через props. Исключение среди текущих элементов —
`SectionPlaceholder`, который сам запрашивает переводы `siteHeader`.

Универсальный компонент добавляй сюда, когда понятно, какие части сайта будут его
использовать. Деталь одного блока может оставаться внутри соответствующего widget.
