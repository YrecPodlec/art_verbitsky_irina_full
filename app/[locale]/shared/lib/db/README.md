# Серверное подключение к MongoDB

[prisma.ts](prisma.ts) экспортирует общий экземпляр Prisma Client.
Он читает `DATABASE_URL` из окружения Next.js. В dev экземпляр сохраняется в
`globalThis`, чтобы обновление кода не создавало множество подключений.

Этот модуль помечен `server-only`: импорт в клиентский компонент запрещён.
Не передавай строку подключения в props и не добавляй префикс `NEXT_PUBLIC_`.
Браузеру доступны только данные, подготовленные сервером, не доступ к базе.

Подключение не знает о проектах и переводах. Предметные запросы находятся в
`entities/project/api`, локализация — в `entities/project/model`.

Генерация клиента, создание коллекции и первый проект:
[инструкция Prisma](../../../../../prisma/README.md).
На Vercel добавь `DATABASE_URL` в Environment Variables нужного окружения
и выполни новый деплой. Токен Blob для чтения публичной картинки не нужен.
