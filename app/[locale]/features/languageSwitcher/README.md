# LanguageSwitcher — смена языка

[ui/LanguageSwitcher.tsx](ui/LanguageSwitcher.tsx) — клиентский компонент навбара.
Стили кнопки и выпадающего списка — в соседнем `LanguageSwitcher.module.scss`.

## Что откуда берётся

- Текущий язык: `useLocale()`.
- Список языков: `routing.locales` из `i18n/routing.ts`.
- Текущий путь без языкового префикса: `usePathname()` из `i18n/navigation.ts`.
- Подписи для доступности: `messages.siteHeader`.
- Флаги: импорты из `shared/assets/flags`, объект `flags`; `en` соответствует флагу США.

Ссылка использует текущий pathname и prop `locale`. Поэтому `/ru/interior`
меняется на `/en/interior`. Query-параметры и hash эта реализация отдельно не переносит.
У языка без флага отображается глобус.

## Зачем хуки и атрибуты

`open` хранит состояние раскрытия. `rootRef` указывает на DOM-контейнер:
через `contains` определяется клик за его пределами. Это не хранение `open`.

Пока список открыт, effect подписывается на клик вне компонента и Escape.
При закрытии или удалении компонента обработчики снимаются.
`useId` создаёт ID списка для `aria-controls`; `aria-expanded` сообщает состояние.
`inert` исключает закрытые ссылки из взаимодействия, `aria-hidden` — из дерева доступности.

## Что менять

Размер и вид кнопки — SCSS. Новая локаль — `routing.ts` и соответствующий JSON;
новый флаг — импорт и объект `flags`.
Подробная инструкция: [i18n](../../../../i18n/README.md).
Источник флагов: [assets](../../shared/assets/README.md).

Проверь смену языка на разных страницах, закрытие по ссылке/вне списка/Escape
и невозможность попасть Tab в закрытый список.
[Назад к features](../README.md).
