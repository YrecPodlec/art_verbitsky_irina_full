# Features — действия пользователя

Каждая папка отвечает за конкретное взаимодействие. Крупную секцию страницы ищи
в [widgets](../widgets/README.md), карточку предмета сайта — в [entities](../entities/README.md).

| Папка | Действие | Где используется |
| --- | --- | --- |
| [projectInquiry](projectInquiry/README.md) | Выбор варианта тарифа, перенос услуги в форму, демо-подтверждение | Услуги и контакты |
| [languageSwitcher](languageSwitcher/README.md) | Выбор языка и раскрытие списка языков | Навбар |
| [sectionNavigation](sectionNavigation/README.md) | Якоря секций, подсветка текущего блока, прогресс, возврат наверх | Страница интерьера |
| [favoriteProject](favoriteProject/README.md) | Заготовка добавления проекта в избранное | Карточки проектов |
| [filterProjects](filterProjects/README.md) | Поиск и URL-фильтры серверного каталога | Галерея |
| [viewProjectMedia](viewProjectMedia/README.md) | Сетка и увеличенный просмотр изображений | Кейсы проектов |
| [profileButton](profileButton/README.md) | Заготовка входа в профиль | Навбар и футер |
| [mainCardFeature](mainCardFeature/README.md) | Список переходов исходной главной страницы | `app/[locale]/page.tsx` |

## Как устроены папки

`ui` содержит компоненты и SCSS; `model` — состояние и поведение,
если они отделены от разметки. Небольшой переключатель может хранить свои хуки в TSX.

`features/index.ts` сейчас экспортирует только старый `MainCardFeature`.
У новых features с собственным `index.ts` импортируй из их папки,
например `@/app/[locale]/features/projectInquiry`.

## Как менять поведение

Проверь, кто хранит состояние и кто его использует. Например, выбранный вариант
карточки — локальный `selected`, а услуга формы — общий `service` в `InquiryProvider`.
Изменение одного не означает автоматического изменения другого.

Клиентская feature получает готовые строки через props либо использует переданный
словарь. Общий провайдер переводов сейчас содержит только `siteHeader`.
Подробности — в [локализации](../../../i18n/README.md).

Для новой возможности профиля или избранного требуется реализовать её поведение,
а не просто убрать `disabled` с кнопки. Их текущее состояние описано в README папок.
