# FavoriteProject — будущие сохранённые проекты

[ui/FavoriteProjectButton.tsx](ui/FavoriteProjectButton.tsx) сейчас является серверной
заготовкой с отключённой кнопкой. Props: `projectId` и переведённый `projectName`.
Тексты доступны в `messages.favoriteProject`, SVG — в `shared/UI/icons/Heart.tsx`.

Внешний вид меняется в соседнем SCSS. Размеры используют переменные
`--favorite-control-size` и `--favorite-icon-size` с запасными значениями:
карточка может уточнять их для плотного планшетного варианта.

`FeaturedProjects` передаёт кнопку в `ProjectCard` через `favoriteAction`.
Карточка не импортирует эту feature и не хранит список сохранённого.

Для запуска возможности потребуются аккаунт, хранение и API, состояние сохранения,
ожидание и ошибки, доступное описание действия. Простое снятие `disabled`
не реализует сохранение. Если действие станет клиентским, серверной карточке
можно продолжать передавать его через тот же слот.

`featured` в данных проекта означает редакционную подборку для портфолио —
это отдельное понятие от избранного пользователя.
