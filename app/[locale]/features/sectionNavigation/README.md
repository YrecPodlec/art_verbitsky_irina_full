# SectionNavigation — навигация по блокам и прогресс

Фиксированные точки сбоку и кнопка наверх подключены только к странице интерьера.

| Файл | Что менять |
| --- | --- |
| [ui/SectionNavigation.tsx](ui/SectionNavigation.tsx) | Разметку якорей, подписи и доступность |
| [ui/SectionNavigation.module.scss](ui/SectionNavigation.module.scss) | Точки, линию прогресса, позицию и адаптив |
| [model/useReadingProgress.ts](model/useReadingProgress.ts) | Измерение прокрутки, выбор активного блока, появление кнопки наверх |

Props: `sections: {id, label}[]`, `label` — название навигации,
`backToTop` — подпись кнопки наверх.
Список и переводы готовятся в [(pages)/interior/page.tsx](<../../(pages)/interior/page.tsx>).

## Алгоритм

Хук получает DOM-элементы по ID. Активным становится последний по порядку блок,
верх которого прошёл отметку 40% высоты окна.
Прогресс — отношение прокрутки к доступной высоте прокрутки, ограниченное от 0 до 1.
Кнопка наверх появляется после 500 px прокрутки.

Scroll и resize планируют один `requestAnimationFrame`, а `ResizeObserver`
замечает изменение высоты страницы, например при раскрытии этапа.
При уходе со страницы подписки, observer и запланированный кадр очищаются.

В UI динамически передаётся только `--reading-progress`; оформление остаётся в SCSS.
У активной ссылки есть `aria-current="location"`.
При ширине до 50rem боковая навигация скрыта; кнопка наверх остаётся доступной после прокрутки.

## Добавить блок

Добавь его ID в `sections` страницы и перевод `sectionNavigation.<id>`.
Проверь, что ID существует у секции, уникален и порядок соответствует странице.
Сам переход работает обычным `href="#id"`; хук не заменяет навигацию.

## Offset при переходе

Позицию остановки задаёт `scroll-padding-top` у html в `globals.css`:
высота шапки + `--anchor-scroll-adjustment`, не ниже нуля.
У Interior восстановлена прежняя поправка **-5rem**: вызов
`useFixedHeaderOffset(headerRef, '-5rem')` в `widgets/siteHeader/ui/SiteHeader.tsx`.
Главная сохраняет отдельную поправку +1rem. Изменение высоты шапки по-прежнему
учитывается через ResizeObserver; после ухода со страницы её поправка очищается.
Если нужна другая позиция Interior, меняй второй аргумент этого вызова.

Проверь короткую и длинную страницу, раскрытие этапов, изменение ширины,
переходы по точкам и возврат наверх.
