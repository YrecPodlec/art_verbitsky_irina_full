# Форма создания проекта

Страница `/ru/admin/projects` (или `/en/admin/projects`) собирается в
[(pages)/admin/projects/page.tsx](<../../(pages)/admin/projects/page.tsx>).
В ней нет чтения БД: она передаёт выбранные переводы в клиентскую форму.

| Файл | Назначение |
| --- | --- |
| [ui/ProjectCreateForm.tsx](ui/ProjectCreateForm.tsx) | Поля проекта и сообщения о результате |
| [ui/ProjectMediaFields.tsx](ui/ProjectMediaFields.tsx) | Одна переиспользуемая группа полей изображения |
| [ui/ProjectCreateForm.module.scss](ui/ProjectCreateForm.module.scss) | Общие модульные стили и адаптив |
| [model/useProjectForm.ts](model/useProjectForm.ts) | Состояние формы, сбор JSON, POST через fetch |
| [index.ts](index.ts) | Публичный вход компонента |

Поля изначально пустые, кроме вариантов типа/категории и статуса «Черновик».
Смена типа меняет доступные категории. Изображения добавляются как группы полей:
URL готового файла, ключ перевода, категория, настоящие ширина/высота.
ID изображения создаётся в памяти формы; это ещё не запись в БД.
По умолчанию обложка — первая картинка; можно выбрать другую.

Все тексты — `messages.projectAdmin` и `messages.projectClassification`.
Название, описание и история проекта не вводятся здесь: их добавляем в
`messages.projects.<contentKey>` отдельно. API сохраняет только ключ и нетекстовые данные.

Сохранение — явный POST, никакого useEffect с автоматической записью.
На время запроса поля выключены. При успехе показывается ID; введённые данные
остаются в форме. При неудаче сохранение автоматически не повторяется.

Серверная проверка находится в `entities/project/model/parseProjectInput.ts`,
запись — в `entities/project/api/createProject.ts`. Проверка HTML в браузере
помогает заполнению, но не заменяет серверную проверку.

Ключ доступа вводится в поле password. Его не нужно путать с паролем MongoDB.
Страница не скрыта от посетителей, но сервер не разрешает запись без правильного ключа.
Подробная настройка и API: [инструкция](../../../api/projects/README.md).
