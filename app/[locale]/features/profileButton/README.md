# ProfileButton — заготовка входа в профиль

[ui/ProfileButton.tsx](ui/ProfileButton.tsx) сейчас выводит неактивный `button`
с пояснением из `messages.siteHeader.profileUnavailable`.
Клик ничего не открывает; маршрута профиля в приложении пока нет.

Prop `mobile` включает вариант с текстом. Он используется в мобильном меню
и футере. Внешний вид — `ProfileButton.module.scss`; футер также задаёт
локальные правила расположения.

Компонент не имеет собственного состояния. В клиентском навбаре он входит
в клиентское дерево и использует переданный словарь `siteHeader`.

При доработке сначала выбери поведение: переход на существующий маршрут
или открытие модального окна. Для перехода нужен Link; для открытия — button
и клиентское управление окном. Затем обнови состояние доступности и подписи.
