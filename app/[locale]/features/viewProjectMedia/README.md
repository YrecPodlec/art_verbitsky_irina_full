# Просмотр изображений проекта

`ui/ProjectMediaGallery.tsx` — адаптивная сетка, миниатюры и нативный `<dialog>`.
`layout="masonry"` — Pinterest-подача визуализаций: CSS-колонки разной высоты,
без обрезки и без большого первого кадра. На узком экране две колонки,
на широком до трёх (фактическое число зависит от доступной ширины).
Остальные категории используют обычный `layout="grid"` по умолчанию.
`model/galleryPresentation.ts` задаёт sizes для обоих вариантов; рядом тесты.
`model/useImageViewer.ts` — ref диалога, выбранный индекс и блокировка прокрутки.
`model/imageNavigation.ts` — чистый циклический переход; рядом тесты.

В props приходят только готовые публичные URL, размеры, alt/caption и словарь
`messages.projectCase.viewer`; токен Blob и Prisma в клиент не попадают.
Клавиши ←/→ переключают изображения, Escape закрывает нативный диалог.
Сетка загружается lazy с quality=90. Указанные sizes позволяют браузеру выбрать
подходящее разрешение с учётом DPR, а не растягивать маленькую версию.
Выбранный кадр в диалоге загружается только при открытии, с `unoptimized`:
это **оригинальный файл из Blob**, без повторного сжатия оптимизатором Next.
Ссылка «Открыть оригинал» открывает тот же файл отдельно в новой вкладке.
Миниатюры остаются маленькими оптимизированными изображениями.
Загрузка и перекодирование файлов в Blob не выполняются. Если сам загруженный
WebP уже содержит артефакты, настройка quality их не восстановит — нужен лучший исходник.
Компонент не изменяет БД и подходит любым категориям `media`.
