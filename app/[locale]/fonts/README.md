# Подключённые шрифты

В `interior/` лежат файлы, которые использует `@font-face`
в [globals.css](../globals.css).

| Файл | Семейство | Переменная |
| --- | --- | --- |
| `interior/voguersansfree.ttf` | `InteriorMain` | `--font-display` |
| `interior/fractal.otf` | `InteriorSecond` | `--font-body` |

Для замены общего шрифта обнови файл/путь и соответствующий `@font-face`.
Для смены шрифта одного компонента меняй его `font-family` или `font`
в соседнем SCSS. Проверяй сокращённую запись `font`: она тоже задаёт семейство.

Сейчас зарегистрированы начертания 400 normal и `font-display: swap`.
Новый вес требует подходящего файла и отдельной записи, если он предусмотрен шрифтом.
Копии в `public/interior/fonts` не подключены этими `@font-face`.

После изменения проверь русские и английские буквы, переносы,
высоту шапки и размеры кнопок. Сведения о лицензии нового шрифта сохраняй вместе с источником.
[Карта приложения](../README.md).
