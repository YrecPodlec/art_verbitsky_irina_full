# Entities — проекты и услуги

Entity хранит предметные данные и отображает их. Пользовательское действие
вроде отправки формы или сохранения проекта относится к feature.

| Папка | Данные | Общий компонент |
| --- | --- | --- |
| [project](project/README.md) | Проекты, изображения, признаки подборки и готовые переводы | `ProjectCard` |
| [service](service/README.md) | Тарифы, варианты и список услуг | `ServiceCard` |

В `model` находятся типы и подготовка данных, в `ui` — карточка и её SCSS.
Данные переводятся серверным адаптером, а ID остаются одинаковыми между языками.

Карточки принимают действия через slots: `favoriteAction` у проекта,
`controls` и `action` у услуги. Поэтому entity не импортирует features.

У `project/index.ts` экспортируются и серверные функции/компоненты.
Его runtime-импорты сейчас предназначены для серверных потребителей.
У услуги серверный адаптер вынесен в `service/server.ts`,
а `service/index.ts` подходит для карточки и типов в клиентском дереве.
