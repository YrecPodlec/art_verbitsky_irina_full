# Direction — направление сайта

Это карточки-входы главной, **не проекты MongoDB**.

- `model/directions.mock.json` — локальный массив объектов, который редактируешь вручную.
- `model/directions.ts` — тип `Direction` и типизированный экспорт массива.
- `ui/DirectionCard.tsx` — один серверный компонент ссылки-картинки.
- `ui/DirectionCard.module.scss` — изображение, затемнение, стрелка и наведение.

Props карточки: `direction` и `index`. Индекс используется только для номера;
React key — стабильный `id`. Тексты читаются по `contentKey` из
`messages.home.directions.items.<contentKey>`. MongoDB не подключается.

`HomeDirections` отвечает за прокрутку/порядок, а не сама карточка.
Тот же массив используется ссылками общего футера. Добавление не требует новых TSX.
Полная инструкция с примером объекта — в [главной](../../(home)/README.md).
