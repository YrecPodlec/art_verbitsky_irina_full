## Какие данные хранить где

В модели: `id`, импорт изображения, `imagePosition`, `featured`, `isDemo`.
`featured` отмечает подборку портфолио; `isDemo` включает демонстрационную подпись.
В `messages.projects.<id>`: название, страна, город, описание, тип пространства и alt.
`getProjects` объединяет данные и переводы. Общие подписи карточки — `messages.projectCard`.

## Props карточки

| Prop | Назначение |
| --- | --- |
| `project` | Готовый локализованный проект |
| `index` | Необязательный номер, форматируется как `01` |
| `href` | Необязательный маршрут существующего кейса |
| `compact` | Плотный планшетный вариант, по умолчанию выключен |
| `imageSizes` | Информация для next/image о размере картинки в раскладке |
| `favoriteAction` | Готовая кнопка избранного или другое содержимое слота |

Без `href` карточка не становится ссылкой и показывает подпись «История проекта — скоро».
С `href` изображение и описание получают переходы. Сам маршрут нужно создать отдельно.
`favoriteAction` расположен вне ссылок карточки, чтобы кнопка не оказалась внутри ссылки.

Изображение использует `fill` и ленивую загрузку. Высота обложки определяется aspect-ratio.
Кадрирование задают классы `center`, `right`, `farRight`.

## Добавить проект

1. Добавить изображение в `public/interior` и импорт в `model/projects.ts`.
2. Расширить `ProjectId` и добавить запись в `projectData`.
3. Добавить полный объект `projects.<id>` в каждую локаль.
4. Выбрать кадрирование и признак демонстрационного контента.
5. Проверить подборку: `FeaturedProjects` фильтрует `featured` и берёт первые три.

Для нового размещения карточки настрой сетку в widget и подходящий `imageSizes`,
а не копируй её разметку. Серверный компонент не импортируй напрямую в клиентский TSX.
