# Главная всего сайта

Маршруты: `/ru`, `/en`. Перенесена из согласованного `maket/home-portal`.
Папка `(home)` — группа Next, скобки в адрес не попадают. Старой страницы
`app/[locale]/page.tsx` больше нет: она заменена на `(home)/page.tsx`.

## Карта

| Где | Что менять |
| --- | --- |
| `layout.tsx` | Отдельная шапка и общий футер этой группы |
| `page.tsx` | Порядок блоков главной, metadata, серверная сборка |
| `home.module.scss` | Тёмная тема только этой группы, сетка, разделитель |
| `widgets/homeHeader` | Фиксированная шапка: server-переводы + небольшой клиентский UI |
| `widgets/homeIntro` | Заголовок, знакомство и увеличенный портрет |
| `widgets/homeDirections` | Правая колонка, подсказка, счётчик и внутренняя прокрутка |
| `entities/direction` | Локальные mock-данные и общий компонент карточки |
| `widgets/homeAbout` | Короткий блок знакомства |
| `widgets/homeContact` | Контакты |
| `widgets/siteFooter` | Один общий футер главной, интерьера, галереи и других публичных страниц |
| `art/page.tsx` | Честная страница-заготовка `/ru/art`, пока нет отдельного арт-раздела |

Пути слоёв — внутри `app/[locale]`. Тексты — `messages.home` и `messages.siteFooter`.
Контактный email — один раз в `shared/config/site.ts`.

## Как добавить карточку

Открой [directions.mock.json](../entities/direction/model/directions.mock.json) и
добавь объект в массив (без запятой после последнего):

```json
{"id": "new-direction", "contentKey": "newDirection", "href": "/new-direction", "image": "/home/new-image.webp"}
```

1. `id` уникальный, `contentKey` указывает на переводы; порядок в массиве = порядок карточек.
2. Добавь `home.directions.items.newDirection` в **оба** JSON, ru/en.
   Нужны `code`, `tag`, `kicker`, `title`, `description`, `action`, `imageAlt`.
   Необязательное `note` выводится под карточкой.
3. Положи изображение в `public/home` и укажи путь без слова `public`.
4. Создай страницу для `href`, если её пока нет. Объект создаёт ссылку, но не маршрут Next.

В MongoDB ничего добавлять не нужно. Хоть 2, хоть 15 карточек используют один
`DirectionCard`. Нумерация и количество вычисляются по массиву, лимита `.slice()` нет.
Изменение файла публикуется со сборкой; в dev обновляется автоматически.

## Как работает прокрутка

У `HomeDirections.module.scss` → `.scroll` ограничена `block-size`, стоит
`overflow-y: auto`, видимая полоса и `tabIndex={0}` на контейнере.
Прокрутка работает мышью/тачпадом, касанием и стрелками после фокуса.
Не используются обработчики wheel, карусели и скачивание коллекции с сервера.
На десктопе колонка sticky под шапкой, на телефоне идёт обычным блоком, но
сохраняет свой скролл. На мобильном границы списка позволяют продолжить скролл страницы.

Высота области и поведение меняются в SCSS виджета, не в массиве данных.
Количество новых объектов не увеличивает высоту всей правой колонки.

## Шапка и футер

`HomeHeader` находится в layout, а не внутри содержимого страницы. Он fixed,
без заданной высоты: общий `useFixedHeaderOffset` измеряет фактическую высоту,
`FixedHeaderShell` резервирует место, якоря учитывают отступ.
Используется **существующий** `LanguageSwitcher` с флагами и выпадающим списком.
Тексты шапки передаются в клиент готовыми строками; вся главная не становится клиентской.

Старый `SiteHeader` теперь подключён только в `(pages)/interior/layout.tsx`.
В locale-layout конкретной шапки нет. Галерея/статьи/шоурум не наследуют её:
свою навигацию для этих направлений можно делать отдельно.

`SiteFooter` общий. Старый импорт `InteriorFooter` оставлен совместимым alias,
но отдельной копии разметки и стилей у него больше нет.

## Изображения и производительность

Портрет — `public/interior/irina.jpg`, крупнее прототипа, без фильтров и обрезки.
Изображения направлений локальные, с Next Image. Art SVG — подписанный эскиз,
не произведение автора. Общая главная и Art не импортируют Prisma и не запрашивают MongoDB.
Prefetch ссылок направлений отключён, чтобы 15 карточек не запустили 15 загрузок страниц.
При добавлении большого количества тяжёлых изображений учитывай размеры/формат файлов.

## Проверки

```powershell
npm run test:home
npm run check:messages
npx tsc --noEmit
npm run lint
# При запущенном Next:
npm run test:home:http
```

HTTP-тесты делают только GET: ru/en, обложки, маршруты, metadata, одна шапка/футер,
ссылки из текущего mock-файла и локальные изображения через оптимизатор.
Тесты модели проверяют полноту переводов, уникальность и отсутствие лимита на 2 карточки.
Тест CSS-контракта не заменяет реальное испытание колеса мыши/касания в браузере.

В браузере проверь 1440/1024/768/390/320 px, фиксированную шапку, раскрытие языка,
мобильное меню, Tab и прокрутку правого списка. Перенос не является деплоем.
