# Сайт Ирины Вербицкой

Next.js 16, React 19, TypeScript и SCSS. Главная страница направления Interior Design собирается по локальному прототипу `maket/` и доступна по `/ru/interior` и `/en/interior`.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000/ru/interior`. Для проверки проекта используйте `npm run check:messages`, `npm run lint`, `npx tsc --noEmit --incremental false` и `npm run build`.

## Где что лежит

- `app/[locale]/` — маршруты и языковой layout Next.js.
- `src/_pages/interior-home/` — порядок секций страницы Interior Design.
- `src/widgets/interior-home/` — самостоятельные секции и общая оболочка направления.
- `src/entities/interior-project/` и `src/entities/interior-service/` — данные и карточки проектов и услуг.
- `src/features/interior-contact/` — поведение демонстрационной контактной формы.
- `public/interior/` — изображения и шрифты из макета.
- `messages/en.json` и `messages/ru.json` — все видимые тексты и метаданные; компоненты запрашивают ключи через `next-intl`.
- `i18n/routing.ts` — список доступных языков, из которого строится переключатель.
- `maket/` — исходный HTML-прототип, визуальный ориентир; это не код работающего Next.js-сайта.

Подробные правила структуры, статус переноса и план проверок: [docs/architecture.md](docs/architecture.md).

## Добавление языка

Скопируйте `messages/en.json` в `messages/<код>.json`, переведите значения, не меняя ключи, и добавьте код языка в `i18n/routing.ts`. Карточки, форма и секции не требуют изменений. Запустите `npm run check:messages`: команда покажет отсутствующие или лишние ключи. Для языков с письмом справа налево понадобится отдельно настроить направление интерфейса и проверить вёрстку.

## Что пока демонстрационное

Проекты, их фотографии и состав тарифов взяты из прототипа и требуют подтверждения. Форма проверяет поля, но не отправляет и не сохраняет данные. Шоурум и остальные страницы прототипа ещё не перенесены.
