## Как поддерживать документацию

После изменения состава файлов, props или поведения обновляй README соответствующей папки.
На верхнем уровне оставляй краткое назначение и ссылку, а подробности — рядом с реализацией.
Примеры с условными данными отмечай явно. Тексты интерфейса остаются в messages:
документация не становится дополнительным словарём приложения.

У небольших UI вроде FloorPlan, MainLinkCards и Tags описание находится в каталоге UI.
Отдельные README для каждого `ui`, `model` и `index.ts` не нужны,
когда их ответственность уже объяснена на уровне компонента.

Исходный макет имеет собственные README и HANDOFF внутри `maket/`.
Они описывают HTML-прототип; текущее Next.js-приложение описывают документы выше.
