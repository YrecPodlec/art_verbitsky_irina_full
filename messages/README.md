# Messages — все переводы проекта

`ru.json` и `en.json` содержат одинаковую структуру ключей с разными значениями.
Тексты компонентов, кнопок, полей, подписи изображений и метаданные находятся здесь.

## Где искать текст

| Раздел JSON | За что отвечает |
| --- | --- |
| `siteHeader` | Бренд, навбар, язык, профиль и заглушки страниц |
| `interiorHero` | Первый экран, его действия и метаданные интерьера |
| `featuredProjects` | Заголовки и переходы второго блока |
| `projects` | Название, место, описание, тип и alt каждого проекта |
| `projectCard` | Общие подписи карточки проекта |
| `favoriteProject` | Подпись сердечка и пояснение недоступности |
| `services` | Тарифы, варианты, названия услуг, цена и консультации |
| `workProcess` | Этапы работы, схема и примечания |
| `designerAbout` | Имя, текст об Ирине и принципы |
| `showroomTeaser` | Превью шоурума |
| `interiorContact` | Левая часть контактной секции |
| `contactForm` | Поля, placeholders, кнопки и демо-подтверждение |
| `interiorFooter` | Собственные тексты футера |
| `breadcrumbs` | Названия страниц в крошках |
| `sectionNavigation` | Подписи боковых якорей и кнопки наверх |

Исходная главная также ожидает `home` и `home.cards`, но этих разделов сейчас нет.
Их нужно восстановить при доработке главной.

## Как компонент находит строку

```tsx
const t = await getTranslations('featuredProjects');
t('gallery'); // значение featuredProjects.gallery
```

Namespace — первый аргумент, внутренний ключ — второй.
Если не находишь текст, найди вызов `getTranslations` / `useTranslations`
или источник props `copy` и `labels` у компонента.

Серверный `InteriorContact` передаёт `contactForm` через props.
Это тоже локализация из JSON; форма не содержит отдельного словаря внутри TSX.

## Что сохранять при изменении

- Ключи и ID между языками должны совпадать.
- Параметры вроде `{name}` и `{locale}` не переименовываются без изменения вызова.
- `<br></br>` и `<accent>…</accent>` используются с `t.rich` для переносов и выделения.
  Это именованные маркеры, которые компонент превращает в JSX.
- Для текста с такими тегами нужен `t.rich` и обработчики тегов, а не обычный `t`.
- `services.variants.<id>.items` — массив строк, а не одна строка; адаптер получает его через `t.raw`.
- В JSON нельзя добавлять комментарии или завершающие запятые.

При добавлении поля формы обнови соответствующий объект в каждой локали.
Тип `ContactFormMessages` выводится из английской структуры — изменяй её согласованно.

Новый язык и флаг описаны в [i18n](../i18n/README.md).
Команда `check:messages` пока не работает, так как её скрипт удалён.
Проверяй совпадение структуры словарей и обе версии страницы в браузере.
