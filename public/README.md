# Public — изображения и публичные файлы

Файлы доступны из корня сайта без слова `public` в адресе.
Например, `public/interior/irina.jpg` соответствует `/interior/irina.jpg`.

| Папка / файл | Текущее назначение |
| --- | --- |
| `interior/interior-evening.png` | Фон первого экрана, часть проектов и превью шоурума |
| `interior/project-placeholder.jpeg` | Демонстрационное изображение проекта |
| `interior/irina.jpg` | Портрет в блоке об Ирине |
| `interior/fonts/` | Копии шрифтов макета; текущие @font-face подключены из app |
| `logo/Logo_white.webp`, `logo/photo.jpg` | Логотип и фото исходной главной страницы |
| `hero.webp` | Фоновое изображение исходной главной |
| Корневые SVG | Файлы начального шаблона; назначения проверяются по импортам и URL |

## Как заменить изображение

Фотографии интерьера импортируются в widgets или в `entities/project/model/projects.ts`.
Можно обновить сам файл либо добавить новый и изменить импорт.
У каждой картинки проверь alt в переводах и кадрирование в SCSS.

Статический импорт используется с `next/image`; он даёт приложению сведения об изображении.
При `fill` размеры картинки определяет контейнер и его CSS,
а `sizes` должен соответствовать реальной раскладке.
Фото с фиксированными исходными width/height также могут масштабироваться CSS.

Влияние замены одного общего `interior-evening.png` проверь во всех его применениях.
Для индивидуальных изображений проектов используй разные файлы и импорты.

Подключённые шрифты описаны в [app/fonts](../app/[locale]/fonts/README.md),
флаги — в [shared/assets](../app/[locale]/shared/assets/README.md).
Файлы этой папки могут запрашиваться по URL: личные материалы, ключи и другие
непубличные данные здесь хранить не следует.
[Карта документации](../docs/README.md).
